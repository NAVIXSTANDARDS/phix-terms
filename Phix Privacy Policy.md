# PhiX - Privacy Policy

**Effective Date:** May 2, 2025  
**Last Updated:** May 2, 2025

This Privacy Policy explains how PhiX ("the Bot", "we", "our", or "us") collects, uses, and protects your data when you use our services on Discord. By using PhiX, you consent to the practices described below.

---

## 1. Data Controller
PhiX is managed by NAVIXSTANDARDS. All data collection and use are overseen by the bot’s developers.

## 2. Scope
This policy applies to all data processed by PhiX across Discord servers where the bot is present.

## 3. Consent
By using PhiX, you consent to the collection and processing of metadata and usage data as outlined in this policy.

## 4. Information Collected
PhiX collects the following:
- Discord User IDs
- Server (Guild) IDs
- Channel IDs
- Role IDs
- Message IDs (for logging/anti-spam)
- Join timestamps
- IP/Device data (only if user interacts with external verification system)

## 5. Metadata Storage
All collected data is limited to metadata. PhiX does not read or store message content except for moderation triggers (e.g., spam detection).

## 6. JoinGate & Threat Profiling
JoinGate checks user IDs against a GitHub-hosted JSON profile system containing public threat metadata. Profiles include type, family, and risk level. These profiles are not shared outside intended use.

## 7. Server Configuration Data
PhiX stores configuration settings per server such as whitelists, subscription type, and verification preferences.

## 8. Subscription Information
PhiX logs the Guild ID, subscription type (trial/monthly/yearly/lifetime), activation code, and expiration date. No billing or payment information is stored.

## 9. No Payment Info Collected
All payments are handled by third-party services (e.g., Stripe, PayPal). PhiX does not collect or store credit card or billing data.

## 10. Verification System
The verification system may temporarily store input images or CAPTCHA data, which is purged after verification is complete.

## 11. Use of Data
Data is used for:
- Detecting raids, nukes, phishing, and spam
- Configuring server-specific security settings
- Displaying security alerts and logs
- Subscription management

## 12. Data Storage Duration
Data is retained as long as necessary to provide service or until a deletion request is made.

## 13. Data Deletion
Server owners may request data deletion by contacting support or removing the bot. Verified requests will be completed within 30 days.

## 14. Data Sharing
PhiX does **not** sell, rent, or trade any user data. Data is only shared with GitHub-hosted systems directly used by the bot.

## 15. Third-Party Services
PhiX integrates with Discord APIs and GitHub. These services have their own privacy policies, which users should review.

## 16. Data Access
Only authorized developers have access to PhiX's stored data. Access is restricted and monitored.

## 17. Children’s Privacy
PhiX does not knowingly collect personal data from individuals under 13. If such data is found, it will be removed immediately.

## 18. Data Protection
We implement basic safeguards (such as access controls and secure storage) to protect data from unauthorized access or leaks.

## 19. Logging
Moderation actions, system warnings, and important events may be logged internally for diagnostic or security reasons.

## 20. Error Tracking
We may collect limited error data such as timestamps and user IDs for debugging purposes. This data is anonymized when possible.

## 21. Abuse Prevention
PhiX automatically flags suspicious activity (e.g., trial abuse, nukes, raids) and logs related metadata for protection.

## 22. Compliance
PhiX aims to comply with GDPR-like standards, including transparency, data minimization, and data access control.

## 23. Policy Changes
We may update this Privacy Policy at any time. Users will be notified via GitHub or bot announcements when major changes occur.
